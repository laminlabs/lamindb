# LaminDB guide

After `pip install lamindb`, the guide is inside the package under `.agents/docs` next to this skill.

In a git checkout, start at `docs/guide.md` and grep `docs/`.

The API reference is created with autodoc. Use `help()` or the Python source. The public index, when the network is available, is https://docs.lamin.ai/llms.txt.
This also contains broader use cases and LaminHub docs.
